Dados desbalanceados
 o O problema de dados desbalanceados é tópico da área de
 classificação de dados.
 o Em vários conjuntos de dados reais, o número de objetos varia
 para diferentes classes.
 o Isso é comum em aplicações em que dados de um subconjunto
 das classes aparecem com uma frequência maior que os
 dados das demais classes.
Dados desbalanceados
 Imagine a seguinte situação:
 o Suponha que 80% das pessoas que estão indo ao hospital hoje
 para verificar se estão com o COVID-19 (do inglês Coronavirus
 Disease 2019) dê NEGATIVO.
 o Neste contexto, 20% dos usuários testados estariam com o
 COVID-19.
 o Assim, a classe com pacientes saudáveis é a classe majoritária e
 a classe de pacientes não saudáveis (com COVID-19) é a classe
 minoritária.
Dados desbalanceados
 o Vários algoritmos de Aprendizado de Máquina têm seu
 desempenho prejudicado na presença de dados
 desbalanceados.
 o Quando alimentados com dados desbalanceados, esses
 algoritmos tendem a favorecer a classificação de novos dados na
 classe majoritária.

O que fazer?
 As principais técnicas para resolver este problema são:
 o Redefinir o tamanho do conjunto de dados
 o Utilizar diferentes custos de classificação para as diferentes
 classes
 o Induzir um modelo para uma classe
Dados desbalanceados
O que fazer?
 ➢Redefinir o tamanho do conjunto de dados
 o Neste caso, podemos tanto adicionar instância à classe
 minoritária (métodos oversampling) quanto remover
 instâncias da classe majoritária (métodos undersampling)
 Problema com os métodos Oversampling:
 o Existe o risco de as instâncias acrescentadas representarem situações em nunca ocorrerão, induzindo
 um modelo inadequado para os dados.
 o Pode ocorrer também o problema de overfitting, em que o modelo é superajustado aos dados de
 treinamento
 Problema com os métodos Undersampling:
 o Quando os dados são eliminados da classe majoritária, é possível que dados de grande importância
 para a indução do modelo correto sejam perdidos.
 o Isso pode levar ao problema de underfitting, em que o modelo induzido não se ajusta aos dados de
 treinamento.
Dados desbalanceados
O que fazer?
 ➢Utilizar diferentes custos de classificação para as
 diferentes classes
 o A utilização de custos de classificação diferentes para as classes
 majoritária e minoritária tem como dificuldade a definição
 desses custos.
 o Por exemplo, se o número de exemplos da classe majoritária for o
 dobro do número da exemplos da classe minoritária, um erro de
 classificação para um exemplo da classe minoritária pode
 equivaler à ocorrência de dois erros de classificação para um
 exemplo da classe majoritária.
 o Entretanto, a definição dos diferentes custos geralmente não é
 tão direta.
Dados desbalanceados
O que fazer?
 ➢Induzir um modelo para uma classe
 o A classe minoritária ou majoritária são aprendidas
 separadamente.
 o Neste caso, pode ser utilizado algoritmo de classificação para uma
 classe apenas.
Dados desbalanceados
O que fazer?
 ➢Importante realizar o balanceamento apenas no conjunto de
 treino. Fazer balanceamento no conjunto completo ocorrerá
 vazamento de dados (data leakage)
 ➢Ou seja, você deve realizar o balanceamento após a divisão de
 treino e teste (train_test_split)
