 Vamos compreender a razão de usar a função fit apenas no treino e usar o predict no
 treino e teste?
 • Cenário
 • Imagine que você já fez o split treino/teste, e está imputando Age usando Fare como referência
 de similaridade (KNN com k=1).
Tratamento de dados ausentes
 • Cenário B (correto): fit só no treino, transform em ambos
 • O "pool de vizinhos" disponível para imputar é só o treino. Calculando a distância de Te1
 (Fare=8.00) até cada um:
 Vizinho mais próximo: T3. Te1 recebe Age = 26 (o valor de T3).
Tratamento de dados ausentes
 • Cenário A (errado): fit no treino + teste juntos
 • Agora o "pool de vizinhos" inclui Te2 também. Recalculando:
 Vizinho mais próximo: Te2 (outra instância do próprio teste!). Te1 recebe Age = 45.
Tratamento de dados ausentes
 • O que aconteceu
 • No Cenário A, o valor imputado para Te1 (26 → 45) mudou só porque Te2
 estava no mesmo lote de avaliação.
 • Isso é o vazamento: em produção, quando Te1 chegar como um passageiro novo
 e real, o sistema não vai ter magicamente acesso a "Te2" para usar como vizinho,
 cada passageiro novo chega sozinho, sem outros casos de teste disponíveis ao
 lado dele.
 • O Cenário B reflete essa realidade; o Cenário A, não.
